# TaskBoard — тестовое приложение для лабораторной работы по CI/CD

Небольшое приложение на Blazor WebAssembly: доска задач, где у каждого этапа
есть лимит незавершённой работы. Нужно как предмет для процесса непрерывной
интеграции и поставки.

## Структура

- `src/TaskBoard` — приложение и доменная логика доски (`Domain/Board.cs`)
- `tests/TaskBoard.Tests` — юнит-тесты на xUnit
- `.github/workflows/ci-cd.yml` — конвейер сборки, тестов и публикации

## Конвейер

| Этап | Когда запускается | Что делает |
|---|---|---|
| Сборка и тесты | push и pull request в `main` | восстанавливает зависимости, собирает решение, прогоняет тесты, сохраняет отчёт |
| Сборка сайта | только `main`, после успешных тестов | публикует Blazor-приложение и готовит статические файлы |
| Развёртывание | только `main`, после сборки сайта | выкладывает сайт на GitHub Pages |

Ветка `main` защищена: прямой push запрещён, изменения приходят через pull request,
который не сливается, пока не прошли тесты.

## Локальный запуск

```
dotnet test
dotnet run --project src/TaskBoard
```
